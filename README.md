# VRM Retro シリーズ

VRM アバターを、ドット絵のスプライト、モーション、レトロな VRM、ペーパークラフト、ガウシアンスプラットにする、5 つの無料ツールの入口のページです。

ページ：https://harukaappscreate.github.io/vrm-retro/

| ツール | できること | 試す |
|---|---|---|
| VRM Retro Viewer | VRM を 8 方向のドット絵スプライトに | https://haruka-apps-games.itch.io/vrm-retro-viewer |
| VRM Motion Studio | 動画（MP4）から VRM のモーション（.vrma）を作る | https://haruka-apps-games.itch.io/vrm-motion-studio |
| VRM RETRO MAKER | VRM をレトロな VRM に。絵からボクセルの VRM に | https://haruka-apps-games.itch.io/vrm-retro-maker |
| VRM RETRO PAPERCRAFT | VRM を印刷できるペーパークラフトに | https://haruka-apps-games.itch.io/vrm-retro-papercraft |
| VRM RETRO 4DGS STUDIO | VRM を動くガウシアンスプラットに | https://haruka-apps-games.itch.io/vrm-retro-4dgs-studio |

どのツールもブラウザだけで動き、ファイルはアップロードされません。

---

Landing page for five free browser tools that turn your VRM avatar into pixel sprites, motions, retro VRMs, papercraft and Gaussian splats.
