# VRM Retro シリーズ

VRM アバターを、ドット絵のスプライト、モーション、レトロな VRM、ペーパークラフト、ガウシアンスプラットにする、デスクトップを歩かせる。7 つの無料ツールの入口のページです（Video → VRM Studio は関連ツールとして下に）。

ページ：https://harukaappscreate.github.io/vrm-retro/

| ツール | できること | 試す |
|---|---|---|
| VRM Retro Viewer | VRM を 8 方向のドット絵スプライトに | https://haruka-apps-games.itch.io/vrm-retro-viewer |
| VRM Motion Studio | 動画（MP4）から VRM のモーション（.vrma）を作る | https://haruka-apps-games.itch.io/vrm-motion-studio |
| VRM RETRO MAKER | VRM をレトロな VRM に。絵からボクセルの VRM に | https://haruka-apps-games.itch.io/vrm-retro-maker |
| VRM RETRO PAPERCRAFT | VRM を印刷できるペーパークラフトに | https://haruka-apps-games.itch.io/vrm-retro-papercraft |
| VRM RETRO 4DGS STUDIO | VRM を動くガウシアンスプラットに | https://haruka-apps-games.itch.io/vrm-retro-4dgs-studio |
| VRM RETRO WALK | VRM がドット絵でデスクトップを歩く（Windows 用アプリ） | https://haruka-apps-games.itch.io/vrm-retro-walk |

関連ツール（シリーズの外。Pyxel ではなく HTML5 / WebGL2）：

| ツール | できること | 試す |
|---|---|---|
| Video → VRM Studio | グリーンバックの 360° 回転動画から VRM アバターを作る | https://haruka-apps-games.itch.io/video-vrm-studio |

VRM RETRO WALK（Windows 用アプリ）のほかは、ブラウザだけで動きます。どのツールも、ファイルはアップロードされません。

---

Landing page for seven free tools that turn your VRM avatar into pixel sprites, motions, retro VRMs, papercraft and Gaussian splats, let it walk on your Windows desktop, or make one from a turntable video (Video → VRM Studio, listed as a related tool).
